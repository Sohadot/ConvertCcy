Pair Overview
PHP / XDR Supranational Valuation Reference

The Special Drawing Right is a reserve asset created and valued by the International Monetary Fund; it also serves as the IMF's unit of account. XDR is not a circulating currency, is not legal tender anywhere and is not traded on the foreign-exchange market, so an XDR pair is not an ordinary currency conversion.

PHP (Philippine Peso) is the counter-currency; see its PHP reference for its own pairs.

The IMF valuation is the governing value of the SDR. Any SDR value in a currency other than the US dollar is derived from that valuation and an FX reference, and is not an IMF quote.

Reading an Institutional-Unit Reference

An institutional unit is defined and valued by an institution — through a currency basket, an official index or an institutional rule — rather than priced by a foreign-exchange market. Its governing value is the one its issuer publishes, on the issuer's own schedule.

A value shown in the unit's own denomination is a direct issuer value. A value in any other currency, or an inverse value, is derived from the issuer valuation and a separate FX reference; both dates are shown, and it is not an issuer quote.

FAQ
Is XDR a currency?
The SDR is not a currency; its value is based on a basket of five currencies: the US dollar, the euro, the Chinese renminbi, the Japanese yen and the British pound sterling. XDR is not a circulating currency, is not legal tender anywhere and is not traded on the foreign-exchange market, so an XDR pair is not an ordinary currency conversion.
Who issues the SDR?
The Special Drawing Right is a reserve asset created and valued by the International Monetary Fund; it also serves as the IMF's unit of account. The SDR is an international reserve asset.
How is the SDR valued?
The currency value of the SDR is determined by summing the US-dollar values of the basket amounts, based on market exchange rates. The IMF calculates the SDR valuation daily, except on IMF holidays, using mid-market rates provided by the Bank of England. The IMF rounds the value of the US dollar in terms of the SDR to six significant digits.
Is this PHP/XDR value published directly by International Monetary Fund?
No PHP/XDR value is shown. ConvertCCY does not publish the IMF SDR valuation: IMF terms require permission for commercial reuse of IMF data, and that permission has not been obtained. When an issuer value is activated, a value in the unit's own denomination is labelled as a direct issuer value and any other currency or inverse value is labelled as derived from the issuer valuation.
What date does this reference use?
None: no value is published, so no valuation date applies. An activated value shows the issuer valuation date and, if derived, the FX reference date as well.
