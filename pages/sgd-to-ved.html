Pair Overview
SGD / VED Code-Status Reference

VED is an ISO 4217 code for the Venezuelan Bolívar Soberano that the ISO maintenance agency describes as introduced for internal needs during the 2021 redenomination; VES remains the official code. VED is a valid ISO code, not an invalid or fictitious currency. No independent VED rate regime exists to state: according to ISO 4217 Amendment 170 the issuer uses VES/928, so any VED figure would be a relabelled VES figure, which ConvertCCY does not apply.

SGD (Singapore Dollar) is the counter-currency; see its SGD reference for its own pairs.

What is the VED currency code?
ISO 4217 lists VED (numeric 926) for Venezuela under the name “Bolívar Soberano”. ISO 4217 Amendment 170 introduced it on 1 October 2021 for internal needs during the redenomination of the bolívar, without replacing VES as the official currency code.
Is VED the same as VES?
Both codes are listed under the name “Bolívar Soberano”. According to ISO 4217 Amendment 170, VES/928 remains the valid code for transactions in the redenominated currency, and the Central Bank of Venezuela will not adopt the new code in its local system. ConvertCCY does not treat VED as an alias of VES and applies no numeric mapping between them.
Why does ConvertCCY not show a VED exchange rate?
No source quotes VED: the FX reference provider used by ConvertCCY does not publish it, and the issuer uses VES/928. No number is shown rather than a relabelled VES value or an estimate.
Does a missing value mean the currency is not real?
No. A missing value means no governed source with an identified rate regime, a valuation date and publication rights is available to ConvertCCY. It says nothing against the validity of the currency or code, and it does not mean that no market exists.
