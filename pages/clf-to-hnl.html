Pair Overview
CLF / HNL Indexed Unit Reference

The Unidad de Fomento is an accounting unit whose peso value follows Chilean consumer-price inflation under official Banco Central de Chile methodology. CLF is not banknotes or coins and is not a floating exchange rate: its peso value is set by an index formula, so CLF to CLP is an indexed value, not an FX quote.

HNL (Honduran Lempira) is the counter-currency; see its HNL reference for its own pairs.

The official CLF value is expressed in Chilean pesos. A CLF value in any other currency would be derived from the official peso value and an FX reference, and is not published by the issuer.

Reading an Institutional-Unit Reference

An institutional unit is defined and valued by an institution — through a currency basket, an official index or an institutional rule — rather than priced by a foreign-exchange market. Its governing value is the one its issuer publishes, on the issuer's own schedule.

A value shown in the unit's own denomination is a direct issuer value. A value in any other currency, or an inverse value, is derived from the issuer valuation and a separate FX reference; both dates are shown, and it is not an issuer quote.

FAQ
Is CLF a currency?
CLF is not banknotes or coins and is not a floating exchange rate: its peso value is set by an index formula, so CLF to CLP is an indexed value, not an FX quote.
What is the Unidad de Fomento?
The Unidad de Fomento is an accounting unit whose peso value follows Chilean consumer-price inflation under official Banco Central de Chile methodology.
How is CLF calculated?
The Unidad de Fomento is calculated each month by Banco Central de Chile. It is adjusted at the geometric average rate corresponding to the change in the Consumer Price Index. Each calculated period runs from day 10 of one month to day 9 of the next.
Why does CLF change over time?
It is adjusted at the geometric average rate corresponding to the change in the Consumer Price Index. The official CLF value is expressed in Chilean pesos. A CLF value in any other currency would be derived from the official peso value and an FX reference, and is not published by the issuer.
Is this CLF/HNL value published directly by Banco Central de Chile?
No CLF/HNL value is shown. ConvertCCY does not yet publish the official CLF value because the reuse terms of the official publication have not been verified. When an issuer value is activated, a value in the unit's own denomination is labelled as a direct issuer value and any other currency or inverse value is labelled as derived from the issuer valuation.
What date does this reference use?
None: no value is published, so no valuation date applies. An activated value shows the issuer valuation date and, if derived, the FX reference date as well.
