Pair Overview
UYW / BIF Indexed Unit Reference

The Unidad Previsional is a statutory Uruguayan accounting unit whose peso value follows the nominal average wage index. UYW is not banknotes or coins and is not a floating exchange rate: its peso value is set by a wage-index formula, so UYW to UYU is an indexed value, not an FX quote.

BIF (Burundian Franc) is the counter-currency; see its BIF reference for its own pairs.

The official UYW value is expressed in Uruguayan pesos. A UYW value in any other currency would be derived from the official peso value and an FX reference, and is not published by INE.

Reading an Institutional-Unit Reference

An institutional unit is defined and valued by an institution — through a currency basket, an official index or an institutional rule — rather than priced by a foreign-exchange market. Its governing value is the one its issuer publishes, on the issuer's own schedule.

A value shown in the unit's own denomination is a direct issuer value. A value in any other currency, or an inverse value, is derived from the issuer valuation and a separate FX reference; both dates are shown, and it is not an issuer quote.

FAQ
What is the Unidad Previsional?
The Unidad Previsional is a statutory Uruguayan accounting unit whose peso value follows the nominal average wage index. The Unidad Previsional was created by Ley N° 19.608 with an initial value of one Uruguayan peso.
How is UYW calculated?
Its value changes daily until it has accumulated the change in the Índice Medio de Salarios Nominales over the previous month.
Who publishes the UYW value?
Uruguay's Instituto Nacional de Estadística administers the unit and publishes its daily value.
Is UYW a currency?
UYW is not banknotes or coins and is not a floating exchange rate: its peso value is set by a wage-index formula, so UYW to UYU is an indexed value, not an FX quote.
Is this UYW/BIF value published directly by Instituto Nacional de Estadística (Uruguay)?
No UYW/BIF value is shown. ConvertCCY does not yet publish the official UYW value because the reuse terms of the INE publication have not been verified. When an issuer value is activated, a value in the unit's own denomination is labelled as a direct issuer value and any other currency or inverse value is labelled as derived from the issuer valuation.
What date does this reference use?
None: no value is published, so no valuation date applies. An activated value shows the issuer valuation date and, if derived, the FX reference date as well.
