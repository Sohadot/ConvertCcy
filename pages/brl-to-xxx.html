Reading an ISO 4217 Special Code

ISO 4217 includes a few codes that are not currencies. A testing code and a no-currency code are standards markers: they denote no money, so no exchange rate, conversion or market price exists for them.

The authoritative explanation of each code is on its standards reference page.

FAQ
Is XXX a currency?
No. In the ISO 4217 code list maintained by SIX, XXX is listed as “The codes assigned for transactions where no currency is involved”. XXX is not a currency, not a tradable asset, not a conversion target and not an exchange-rate instrument.
What does XXX mean in ISO 4217?
XXX is a semantic marker, not money: it denotes that no currency is involved in a transaction or record. XXX does not mean an amount of zero in some currency; it marks that no currency is involved at all.
