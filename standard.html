CRIS v1.0

Currency Rules Integrity Standard

The specification that defines what makes a jurisdictional foreign exchange rules statement trustworthy, auditable, and reference-grade. Every country entry on ConvertCCY is tested against CRIS v1.0.

Foundation Principle

Why CRIS Exists

In 2026, anyone can generate thousands of pages about currency rules using an AI. The buyer of reference-grade data asks: What makes your rules trustworthy?

ConvertCCY's answer is not reputation. It is a named, versioned, public standard that any reader can audit against. CRIS v1.0 defines the structural, sourcing, and editorial requirements for every country rules entry to be considered reference-grade.

Core Claim

A country rules entry is reference-grade if and only if it passes CRIS v1.0 validation. Passing means: sources are official, every claim is attributed, content is distinct and substantial, and the entry's lifecycle is transparent.

The Five Principles

CRIS Architecture

Principle 1: Official Source Authority
All Claims Must Cite Official Sources
Every statement in a country rules entry must map back to an official source: a central bank, customs authority, ministry, or regulator. Secondary sources (news, law firms, multilateral banks) are allowed as supporting references but not as primary claims. Broken URLs or inaccessible sources fail this principle.
Principle 2: Per-Field Attribution
Granular Source Mapping
It is not enough to say "source: the central bank." Every rule field (declaration threshold, import rules, residency rules, etc.) must specify which source authority and which section or page number supports that claim. Attribution is granular, not global.
Principle 3: Semantic Distinctness
Content Must Reflect Actual Regulatory Difference
If a jurisdiction has different rules for bringing in vs. taking out currency, the text must reflect that difference. No placeholder replication. If the rules are genuinely identical, they must be rewritten to show the actual regulatory framework so the difference becomes clear. Textual similarity >72% is rejected.
Principle 4: Regulatory Literacy
Evidence of Domain Knowledge
The country overview must demonstrate understanding of the jurisdiction's regulatory regime: the name of the regulatory authority, the type of exchange-rate regime (floating, pegged, controlled), and the convertibility status (freely convertible, restricted, non-resident convertible). Generic or placeholder text fails.
Principle 5: Transparent Lifecycle
Clear Publication Status
Every entry must declare its evidence tier (official_verified, official_verified_partial, secondary_institutional, internal), publication status (published, verified, needs_hardening, blocked), and last review date. No silent edits. Changes are appended, dated, and explained. Readers can audit the entry's history.
Specification

CRIS v1.0 Validation Schema

Field Requirements

Every country rules entry must include these fields, and each must conform to CRIS v1.0:

country_name Non-empty string. Official English name.
iso2, iso3 Valid ISO 3166-1 codes. Required for data interoperability.
currency_code Valid ISO 4217 code. The jurisdiction's primary currency.
country_overview ≥200 characters. Must contain three regulatory signals: regulatory_authority, fx_regime, convertibility_or_controls. No placeholder text.
rules.bring_foreign_currency_in ≥80 chars. Specific to import. Cite official threshold if any.
rules.take_foreign_currency_out ≥80 chars. Specific to export. Must differ meaningfully from import rule (>28% textually distinct).
rules.cash_declaration_threshold ≥80 chars. State the official threshold amount, currency, and which authorities enforce it.
source_authorities[] List of official sources with label, URL (HTTPS), type (central_bank, customs, ministry, etc.), and tier (primary or secondary).
source_map Object. Every rule field maps to specific sources with page numbers (for PDFs on published entries).
last_reviewed ISO 8601 date. When the entry was last audited against official sources. Stale dates raise concerns.
page_status One of: published, verified, needs_hardening, needs_source_review, blocked. Transparent lifecycle.

Source Requirements

CRIS v1.0 enforces strict source discipline:

✓ Official sources that qualify: - Central Bank - Customs Authority - Ministry of Finance / Economy - Financial Regulator - Official Trade/Commerce Agency ✓ Secondary sources (supporting only): - Law firm analysis - Big Four accounting firm guides - Chamber of Commerce reference - Multilateral bank (IMF, World Bank) ✗ Disqualified sources: - News articles (no original research authority) - Reddit / forums / blogs - Outdated or archived pages (>6 months old without review) - Paywalled sources (inaccessible)

What Makes This Compliant

All required fields present. All claims cite official sources (BoC, CBSA). Import and export rules differ substantively (both can export, but residents must report). Last reviewed date is current.

Adoption & Future

CRIS as Public Standard

CRIS v1.0 is published openly. Other reference systems, fintech platforms, compliance tools, and AI agents can adopt it. Debate it. Improve it. The standard is ConvertCCY's public contribution to the infrastructure of trust in global financial reference data.

CRIS v1.0 is final as of 2026. Future versions will be numbered (v1.1, v2.0, etc.) and will not break backward compatibility without major version change.
