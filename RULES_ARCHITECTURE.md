# ============================================================
# PAGE STATUS WORKFLOW
# ============================================================
#
# draft             → Data entered, not yet validated
# needs_source_review → Content written but sources need verification
# verified          → All gates passed, sources confirmed → PUBLISHABLE
# published         → Live on site
# blocked           → Known issue, do not publish
#
# Only verified + published appear on the public site.
# All others exist in data/ but generate no public HTML.
#
# ============================================================
# BUILD COMMANDS
# ============================================================
#
# Validate all country files:
#   python scripts/validate_rules.py data/rules/
#
# Validate single file:
#   python scripts/validate_rules.py data/rules/morocco.json
#
# Dry run (validate only, no output):
#   python scripts/generate_rules.py --dry-run
#
# Full build:
#   python scripts/generate_rules.py
#
# Custom paths:
#   python scripts/generate_rules.py --data-dir data/rules --output-dir rules
#
# ============================================================
