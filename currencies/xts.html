XTS — ISO 4217 Testing Code

ISO 4217 code XTS · ISO 4217 testing code

Standards code · not a currency · no exchange rate · no conversion.

What XTS means

ISO 4217 designation: “Codes specifically reserved for testing purposes” — SIX (ISO 4217 Maintenance Agency).

XTS is not money: the ISO 4217 Maintenance Agency reserves it for testing purposes.

Why XTS exists

A testing code gives systems a valid ISO 4217 code that does not denote real money.

Why XTS has no exchange rate

Because XTS denotes no money, it has no exchange rate and no conversion against any currency.

XTS vs real currencies

XTS is not legal tender, not a circulating currency, not a tradable asset and not an exchange-rate instrument.

Implementation considerations

Treat XTS as a test value only; it should not appear as the currency of a real amount.

Source and standards provenance

  • XTS has the ISO 4217 numeric code 963. — SIX (ISO 4217 Maintenance Agency)
  • The ISO 4217 list gives XTS no minor units (N.A.). — SIX (ISO 4217 Maintenance Agency)
  • The cited ISO 4217 list was published on 2026-09-17. — SIX (ISO 4217 Maintenance Agency)
  • SIX is the official Maintenance Agency of the currency codes under ISO 4217. — SIX (ISO 4217 Maintenance Agency)

XTS FAQ

Is XTS a real currency?

No. In the ISO 4217 code list maintained by SIX, XTS is listed as “Codes specifically reserved for testing purposes”. XTS is not legal tender, not a circulating currency, not a tradable asset and not an exchange-rate instrument.

What is XTS used for?

A testing code gives systems a valid ISO 4217 code that does not denote real money. Treat XTS as a test value only; it should not appear as the currency of a real amount.

Does XTS have an exchange rate?

Because XTS denotes no money, it has no exchange rate and no conversion against any currency.

Why does ConvertCCY list XTS pair pages?

ConvertCCY covers every code in its ISO 4217 set, so pair pages exist for completeness. They are contextual references that are not indexed; this page is the authoritative XTS reference.
