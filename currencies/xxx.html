XXX — ISO 4217 No-Currency Code

ISO 4217 code XXX · symbol ¤ · ISO 4217 code for transactions without a currency

Standards code · not a currency · no exchange rate · no conversion.

What XXX means

ISO 4217 designation: “The codes assigned for transactions where no currency is involved” — SIX (ISO 4217 Maintenance Agency).

XXX is a semantic marker, not money: it denotes that no currency is involved in a transaction or record.

Why XXX exists

It lets a system state explicitly that no currency applies, instead of leaving the currency field empty or guessing one.

Why XXX has no exchange rate

Because XXX denotes the absence of a currency, there is nothing to convert and no exchange rate exists.

XXX vs real currencies

XXX is not a currency, not a tradable asset, not a conversion target and not an exchange-rate instrument.

Implementation considerations

XXX does not mean an amount of zero in some currency; it marks that no currency is involved at all.

Source and standards provenance

  • XXX has the ISO 4217 numeric code 999. — SIX (ISO 4217 Maintenance Agency)
  • The ISO 4217 list gives XXX no minor units (N.A.). — SIX (ISO 4217 Maintenance Agency)
  • The cited ISO 4217 list was published on 2026-09-17. — SIX (ISO 4217 Maintenance Agency)
  • SIX is the official Maintenance Agency of the currency codes under ISO 4217. — SIX (ISO 4217 Maintenance Agency)

XXX FAQ

Is XXX a currency?

No. In the ISO 4217 code list maintained by SIX, XXX is listed as “The codes assigned for transactions where no currency is involved”. XXX is not a currency, not a tradable asset, not a conversion target and not an exchange-rate instrument.

What does XXX mean in ISO 4217?

XXX is a semantic marker, not money: it denotes that no currency is involved in a transaction or record. XXX does not mean an amount of zero in some currency; it marks that no currency is involved at all.

Can XXX be converted into another currency?

Because XXX denotes the absence of a currency, there is nothing to convert and no exchange rate exists.

Why does ConvertCCY list XXX pair pages?

ConvertCCY covers every code in its ISO 4217 set, so pair pages exist for completeness. They are contextual references that are not indexed; this page is the authoritative XXX reference.
