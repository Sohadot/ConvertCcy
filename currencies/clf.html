CLF — Chile Unidad de Fomento

ISO 4217 code CLF · inflation-indexed unit of account

Institutional unit · not a circulating currency · methodology only.

Institutional identity

  • ISO 4217 designation: Unidad de Fomento — SIX (ISO 4217 Maintenance Agency)

Instrument type: Inflation-indexed unit of account (A4.1 class unit_of_account) · Issuer: Banco Central de Chile · Status: active

Purpose and role

The Unidad de Fomento is an accounting unit whose peso value follows Chilean consumer-price inflation under official Banco Central de Chile methodology.

CLF is not banknotes or coins and is not a floating exchange rate: its peso value is set by an index formula, so CLF to CLP is an indexed value, not an FX quote.

Definition and valuation methodology

  • The Unidad de Fomento is calculated each month by Banco Central de Chile. — Comisión para el Mercado Financiero de Chile / Banco Central de Chile methodology
  • It is adjusted at the geometric average rate corresponding to the change in the Consumer Price Index. — Comisión para el Mercado Financiero de Chile / Banco Central de Chile methodology
  • Each calculated period runs from day 10 of one month to day 9 of the next. — Comisión para el Mercado Financiero de Chile / Banco Central de Chile methodology

Current status

  • Chile's Servicio de Impuestos Internos publishes daily values of the Unidad de Fomento. — Servicio de Impuestos Internos (Chile)

Valuation state

METHODOLOGY ONLY · ConvertCCY does not yet publish the official CLF value because the reuse terms of the official publication have not been verified.

The official CLF value is expressed in Chilean pesos. A CLF value in any other currency would be derived from the official peso value and an FX reference, and is not published by the issuer.

Source governance

  • Official valuation source: Banco Central de Chile methodology; daily values published by official Chilean bodies
  • Methodology: CPI-indexed geometric daily adjustment
  • Update frequency: daily values, calculated per monthly period
  • Publication schedule: monthly period published in advance
  • Unit definition: indexed peso value
  • Reference basket: not applicable (single-currency index unit)
  • Historical continuity: continuous official series
  • Redistribution: license_unclear (terms not verified)

CLF FAQ

Is CLF a currency?

CLF is not banknotes or coins and is not a floating exchange rate: its peso value is set by an index formula, so CLF to CLP is an indexed value, not an FX quote.

What is the Unidad de Fomento?

The Unidad de Fomento is an accounting unit whose peso value follows Chilean consumer-price inflation under official Banco Central de Chile methodology.

How is CLF calculated?

The Unidad de Fomento is calculated each month by Banco Central de Chile. It is adjusted at the geometric average rate corresponding to the change in the Consumer Price Index. Each calculated period runs from day 10 of one month to day 9 of the next.

Why does CLF change over time?
