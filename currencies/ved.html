VED — Bolívar Soberano

ISO 4217 code VED · transitional ISO 4217 code

Transitional ISO 4217 code · no governed value available.

Identity

  • ISO 4217: ISO 4217 lists VED, numeric code 926 with 2 minor units, for Venezuela under the currency name “Bolívar Soberano”; VES, numeric code 928, carries the same name. — SIX Financial Information AG, ISO 4217 Maintenance Agency
  • ISO 4217: ISO 4217 Amendment 170, effective 1 October 2021, introduced VED/926 to represent the redenominated valuation “for any internal needs during the redenomination process, but is not replacing VES as the official currency code”. — SIX Financial Information AG, ISO 4217 Maintenance Agency
  • ISO 4217: The same amendment states that the Central Bank of Venezuela will not adopt the new codes in its local system and that VES/928 remains the valid code for any future transactions in the redenominated Bolívar Soberano. — SIX Financial Information AG, ISO 4217 Maintenance Agency

Role: Transitional ISO 4217 code · Issuer or authority: Banco Central de Venezuela

Operative code per ISO 4217: VES — Venezuelan Bolívar reference. No value is copied from VES to VED.

Status and role

VED is an ISO 4217 code for the Venezuelan Bolívar Soberano that the ISO maintenance agency describes as introduced for internal needs during the 2021 redenomination; VES remains the official code. VED is a valid ISO code, not an invalid or fictitious currency.

Source coverage

  • The FX reference provider used by ConvertCCY (exchangerate-api.com) publishes no VED value; checked 2026-11-19. — exchangerate-api.com

Availability and rate regime

TRANSITIONAL ISO CODE · No governed VED value is published: the FX reference provider does not quote VED, the issuer does not use the code in its local system according to ISO 4217 Amendment 170, and the issuer website could not be accessed during the audit.

No independent VED rate regime exists to state: according to ISO 4217 Amendment 170 the issuer uses VES/928, so any VED figure would be a relabelled VES figure, which ConvertCCY does not apply.

VED FAQ

What is the VED currency code?

ISO 4217 lists VED (numeric 926) for Venezuela under the name “Bolívar Soberano”. ISO 4217 Amendment 170 introduced it on 1 October 2021 for internal needs during the redenomination of the bolívar, without replacing VES as the official currency code.

Is VED the same as VES?

Both codes are listed under the name “Bolívar Soberano”. According to ISO 4217 Amendment 170, VES/928 remains the valid code for transactions in the redenominated currency, and the Central Bank of Venezuela will not adopt the new code in its local system. ConvertCCY does not treat VED as an alias of VES and applies no numeric mapping between them.

Why does ConvertCCY not show a VED exchange rate?

No source quotes VED: the FX reference provider used by ConvertCCY does not publish it, and the issuer uses VES/928. No number is shown rather than a relabelled VES value or an estimate.
