Static Agent Interface

This page explains how AI agents, scripts, and other automated systems can read ConvertCCY's published, governed currency-rules data. This is not a dynamic API. It is a static, read-only data interface: plain JSON files generated at build time from published data, served by GitHub Pages exactly like any other file on this domain.

What This Is

Static files, not a running service

Every route below is a file on disk, regenerated whenever the published, source-mapped country data changes, and committed to this repository like any other page. There is no process listening for requests, no query parameters that change behaviour, and no per-request computation. Reading one of these files is the same operation as reading /rules/dataset.json — the open dataset this site has published since its first governance phase.

  • No server executes a request — files are served statically
  • No API keys exist or are required
  • No authentication or account exists
  • No billing or metering exists on this domain
  • No checkout or payment surface exists anywhere on convertccy.com
  • No user input is processed server-side
Machine Entry Point

Start at /api/v1/index.json

The entry point lists every available endpoint, the current count of published jurisdictions, and links to this documentation. From there, an agent can walk to the rules index, a specific country file, or the Passage Check dataset.

/api/v1/index.json
Entry point: endpoint map, published-jurisdiction count, links to documentation and llms.txt.
/api/v1/rules-index.json
Index of all published jurisdictions with links to each per-country file, rules page, and brief.
/api/v1/rules/<country-slug>.json
Full governed rules entry for one published jurisdiction — overview, rule fields, sources, review date.
/api/v1/passage-check.json
Passage Check engine dataset: declaration thresholds and exchange-control posture, transcribed from governed data, each tagged with its source field.

A generated, browsable index of these routes and the currently published jurisdictions is also available at /api/.

Machine Contract

Every file carries the same header

Each JSON file includes a consistent set of fields so an automated consumer can verify scope and boundary without leaving the file:

{ "schema_version": "1.0.0", "generated_at": "...", "asset": "ConvertCCY", "interface_type": "static_agent_interface", "dynamic_api": false, "source_scope": "published_governed_data_only", "license": "CC BY 4.0 — https://creativecommons.org/licenses/by/4.0/", "attribution": "ConvertCCY (https://convertccy.com/)", "disclaimer": "...", "use_boundary": "...", "canonical_url": "...", "documentation": "https://convertccy.com/api.html" }
Coverage Boundary

Published jurisdictions only — never a preview draft

These files are generated only from data that has already passed ConvertCCY's six-gate publication pipeline (see Governance). Nothing under /preview/, nothing marked verified or needs_hardening, and no internal or draft entry is ever exposed here. A build-time guard refuses to generate these files at all if the published dataset and the Passage Check dataset disagree on which jurisdictions qualify.

A currency is not a country

Several published jurisdictions share a currency with countries that are not published (for example, EUR is shared across the Eurozone). Do not infer that a currency code implies coverage of every country that uses it. Always check the country_slug and the jurisdiction list in /api/v1/rules-index.json.

Use Boundary

Reference data, not advice

This data is a governed reference layer, not legal, tax, customs, compliance, or financial advice. It does not predict exchange-rate movement, does not hedge or recommend hedging, and makes no claim about financial performance or outcome. Time-sensitive figures (thresholds, forms, agency names) should be verified against the official source linked in each entry before anyone relies on them for a real border crossing or transaction.

  • Not legal, tax, customs, or compliance advice
  • Not a prediction of future rates or regulatory changes
  • Not a hedging, trading, or financial-performance claim
  • Not a substitute for checking the official source before acting

Roadmap Boundary

Any future metered API is isolated off this domain

ConvertCCY's security posture depends on convertccy.com staying a static, zero-runtime site with no backend, no secrets, and no authentication surface. If a metered or authenticated API is ever built, it will be hosted separately — for example at api.convertccy.com — so that it cannot share this domain's origin, trust, or attack surface. This is a binding decision, recorded in the project's decision log, not a future promise made lightly.

For AI Agents

Read /llms.txt first

Agents and language models should read /llms.txt for citation guidance and usage boundaries before consuming this data, then fetch /api/v1/index.json as the machine entry point.
